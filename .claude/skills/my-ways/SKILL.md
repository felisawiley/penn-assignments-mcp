# My ways with the assignments server

Call the server for dates. Never invent a due date, a point value, or a
course list from memory of an earlier chat.

When I ask what's due, or what I should work on, call `due_this_week` once.
Lead with the week the tool names. An item marked submitted, graded, or
excused is not a to-do — say it's already in, and talk about what is still open.

When I ask what to do first, what is worth the most, how long something
takes, or what my grade is, call `priorities` once. It is six lists:
due soonest, most points, least stated time, most stated time, the grade
in each course, and the unweighted mean of those scores. A time is real
only when the line says "stated time". Do not turn points into minutes.
The semester figure is not a credit-weighted GPA. If `priorities` is
unavailable, say so and use `due_this_week`. Do not invent the ranking.

When I ask how to do the work and still have a life, do not turn the
due-soonest list into a schedule yet. Ask, in one message, what is already
fixed outside class this week and which hours should stay empty. If a
calendar is connected, read this week from every connected account, merge
the events, show me that list, and ask only about what the calendars do
not know. Pass what I confirm as `outside` to `priorities`. Do not invent
a block. Do not put schoolwork on top of a fixed block. Leave the empty
hours empty.

When I name a class, or I want to talk about an assignment — what it asks,
where it sits in the modules, or the file that goes with it — call
`assignments` with that name or code. The line names the module and links
files or pages that sit with it or share its title. Open those links.
Do not invent a file, a page, or a module that is not on the line.
Use `canvas` only when I ask who's teaching, the module list itself, or
what was just announced.

When I ask whether the week is heavy, or what's coming after this week,
call `academic_week` once. Don't re-fetch it to narrate the same load again.

If a tool says I'm a guest, or that this Canvas belongs to someone else,
stop. Tell me to sign in. Do not fill the gap with a guessed syllabus.

When the conversation is not about courses, deadlines, or workload, do
nothing with this server and say nothing about it. A coursework tool that
interjects is worse than no tool.
