# My ways with the assignments server

Call the server for dates. Never invent a due date, a point value, or a
course list from memory of an earlier chat.

When I ask what's due, or what I should work on, call `due_this_week` once.
Lead with the week the tool names. An item marked submitted, graded, or
excused is not a to-do — say it's already in, and talk about what is still open.

When I name a class, call `assignments` with that name or code. Use
`canvas` only when I ask who's teaching, what's in the modules, or what
was just announced.

When I ask whether the week is heavy, or what's coming after this week,
call `academic_week` once. Don't re-fetch it to narrate the same load again.

If a tool says I'm a guest, or that this Canvas belongs to someone else,
stop. Tell me to sign in. Do not fill the gap with a guessed syllabus.

When the conversation is not about courses, deadlines, or workload, do
nothing with this server and say nothing about it. A coursework tool that
interjects is worse than no tool.
